# Wishket 외주 지원 리포트 - Proxmox 7노드 클러스터 구축 및 VM 이전 (kt cloud → 자체 물리 서버)

## 1. 프로젝트 개요
- **공고 URL**: https://project.wishket.com/project/159729/
- **공고명**: Proxmox 7노드 클러스터 구축 및 VM 이전 (kt cloud → 자체 물리 서버)
- **발주처**: 경기 성남시 분당구 소재 IT 인프라/서비스 운영 기업
- **근무 형태**: 100% 원격(화상/전화 미팅 중심) 협업 (도급/외주)

- **지원 제안 금액**: **1,500,000원 (50% 특별 할인가)** / **5일 완료**

## 2. 주요 과업 및 기술 스택
- **주요 업무**:
  - Proxmox VE 7노드 클러스터링 구성 및 HA/Corosync 전용 네트워크 분리
  - Ceph / NFS / iSCSI 공유 스토리지 및 노드 페일오버 정책 정밀 검증
  - kt cloud 인프라의 기존 VM 백업, 이미지 변환(VirtIO 호환성 확인), 증분 복제 마이그레이션 파이프라인 수립
  - 비핵심 VM 시범 이전 검증 후 야간 컷오버(Cut-over)를 통한 서비스 다운타임 최소화
  - Proxmox 백업 스케줄링(PBS) 및 인프라 운영/장애 조치 매뉴얼 제공
- **기술 스택**: Proxmox VE, KVM/QEMU, Linux (CentOS/Ubuntu/Debian), kt cloud, Ceph/NFS, Bash/Ansible
