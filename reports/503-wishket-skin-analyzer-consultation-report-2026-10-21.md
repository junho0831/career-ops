## 1. 프로젝트 개요 및 핵심 과업

- **고객사 요구사항**:
  - 서울 다지점 피부미용 의료기관에서 3D AI 피부진단기 도입에 맞춰, 진단기 분석 결과를 상담 화면에 실시간 시각화하고 환자별 맞춤 시술 추천 및 상담 리포트를 자동 생성하는 내부용 웹 소프트웨어 구축.
  - 의료진과 상담직원이 대형 모니터 및 태블릿에서 직관적으로 조작할 수 있는 터치 반응형 UI/UX.
  - 진단기 자체 AI의 분석 결과(피부결·색소·주름·탄력 등)를 수신하여, 병원 정의 룰에 따른 보유 기기 및 권장 샷 수 자동 추천 → 의료진 수정/확정 → 환자용 PDF/모바일 리포트 출력.
- **핵심 기술 도전 과제**:
  - 장비 API 연동(미제공 시 로컬 감시 에이전트 대안 구축).
  - 대형 모니터 및 태블릿 크로스 디바이스 시각화(얼굴 부위별 문제점 및 피부 단면 깊이 매핑).
  - WebSocket 실시간 결과 푸시 및 서버리스 고품질 PDF 리포트 렌더링.

## 2. 박준호 파트너 매칭 역량 (Fact-based)

- **WebSocket 실시간 관제 및 이벤트 기반 통신 아키텍처**:
  - 반도체 장비 실시간 공정 데이터 파이프라인 및 WebSocket 관제 시스템 구축 경험을 바탕으로, 피부진단기 측정 완료 직후 상담 화면에 딜레이 없는 실시간 동기화 구현.
- **데이터 정합성 및 룰 엔진 설계 경험**:
  - SafeCash 간편결제 시스템 구축 시 금융 결제 원장 무결성 검증(0건 금융사고 달성) 노하우로, 복합 시술 조합 및 점수 구간별 권장 샷 수 규칙을 누락 없이 정확하게 산출하는 룰 엔진 설계.
- **React + Node.js 풀스택 및 PDF 자동 렌더링**:
  - 태블릿 최적화 React SPA 터치 인터페이스 및 Puppeteer 기반 정밀 PDF 리포트(차트, 얼굴 부위 오버레이 포함) 생성 파이프라인 완비.
- **100% 원격 협업 체계**:
  - 비동기 Daily/Weekly 리포트, 슬랙/노션을 통한 실시간 개발 프리뷰 URL 제공 및 온라인 화상 미팅.

## 3. 제안서 핵심 내용 요약

- **적합 기술 스택**: React 18, TypeScript, Tailwind CSS (프론트) / Node.js (NestJS), WebSocket (백엔드) / PostgreSQL 또는 MongoDB (DB) / Docker, AWS (인프라).
- **장비 연동 미확정 대안 제시**:
  - 제조사 공식 REST/WebSocket API 제공 시 직접 연동.
  - API 미제공 시: 장비 전용 PC의 로컬 DB(SQLite/MDB) 또는 내보내기 폴더를 실시간 감시하는 경량 File Watcher 에이전트를 개발하여 100% 무인 자동 전송 보장.
- **피부층 시각화 제안**: 1차 버전은 직관적이고 로딩이 빠른 2D 벡터 단면 레이어(표피·진피·피하지방·SMAS)로 시술 깊이/샷 수를 명확히 표현, 2단계에서 Three.js 3D 모델로 고도화 권장.
- **1차 vs 차기 로드맵 분리**: 1차 60일 내 진단기 연동, 상담 화면, 시술 추천, PDF 리포트 완결 / 차기 EMR 차트 연동 및 다국어 확장.
